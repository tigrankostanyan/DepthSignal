# Periodic Reviews — QuantScreen

## 1. Monthly Review
- Review WAF logs and blocked requests
- Check failed login attempts (trend)
- Review Dependabot/Snyk alerts (open vulnerabilities)
- Check monitoring dashboards for anomalies
- Review any security incidents from the past month

**Owner:** Security Lead / DevOps

## 2. Quarterly Review
- Run vulnerability scanning (Nessus/OpenVAS) on entire infrastructure
- Review cloud security posture (AWS Trusted Advisor, Azure Security Center)
- Update threat model based on new features
- Review and update runbooks (if needed)
- Ensure backups are being created and are healthy

**Owner:** Security Lead / DevOps

## 3. Semi-Annual Review
- Internal penetration test (gray-box) or external pentest
- Review OWASP ASVS checklist and update status
- Conduct tabletop exercise
- Review incident response plan and practice
- Update security training content

**Owner:** Security Lead / CTO

## 4. Annual Review
- Full security audit (OWASP ASVS Level 3)
- External penetration test (black-box)
- Review and update all security policies
- Assess compliance with GDPR/CCPA requirements
- Update threat model for the next year
- Plan security budget for the next year

**Owner:** CTO / Security Lead

## 5. Responsibilities
| Role | Monthly | Quarterly | Semi-Annual | Annual |
|------|---------|-----------|-------------|--------|
| Security Lead | Lead | Lead | Lead | Lead |
| DevOps | Support | Lead | Support | Support |
| Backend Lead | - | Support | Support | Support |
| CTO | - | - | Approve | Approve |
